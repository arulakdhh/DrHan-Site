Dr. Han Healthcare - Website source code
=========================================

index.html            Main site (red, light theme with animated banner and Meril section)
index-teal-dark.html  Earlier teal/navy version (backup)

Each file is self-contained: all HTML, CSS and JavaScript are inside the one file.
Only the Google Fonts (Fraunces, Inter) load from the internet.

To view: double-click index.html to open it in any browser.

To publish (free):
  1. Go to https://app.netlify.com/drop
  2. Drag this whole folder onto the page.
  3. Your site is live. Add your own domain under Domain settings.

To edit:
  - Open index.html in a code editor (VS Code is free).
  - Replace "[Add company email]" and "[Add company phone]" in the Contact section.
  - Colours are set at the top of the <style> block (--teal is the main red accent).
  - Meril specialty areas and descriptions are in the "MERIL WHEEL" script near the bottom.
